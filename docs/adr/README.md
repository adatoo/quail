# Architecture decision records

Each file here records one decision about Quail: what was decided, the alternatives, and what would make us revisit it.

- ADRs live in `docs/adr/NNNN-title.md` and are listed below. Numbers are never reused.
- An ADR describes the decision as it stands. When the decision changes, edit the ADR in place: rewrite whatever is no longer true and update its date and status. Don't add amendment sections or a superseding ADR; git history records what it used to say.
- If a decision is dropped entirely, set its status to `Withdrawn`, with a line on why.
- Changing a decision needs the owner's explicit instruction. Updating an ADR to match a decision already made does not.
- Refer to an ADR as `ADR-NNNN`.

ADR-0001 to ADR-0072 were moved here on 2026-10-12 from the single decisions file they used to share. Some of them still carry that file's older "Amended" and "Superseded by" notes.
