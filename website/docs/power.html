Power

A Mac that goes to sleep takes the server with it. Quail can keep it awake while the server runs.

Keep this Mac awake while the server runs

Server → Power, or Keep Mac Awake While Serving in the menu. It stops idle sleep, as caffeinate does, so a long download, benchmark or agent session isn't cut off. The display can still turn off.

Also with the lid closed, when plugged in

macOS puts a laptop to sleep when its lid closes, whatever an app asks. With this on, Quail turns sleep off for the whole Mac while the server runs on power. It asks for your password the first time the server starts.

Sleep comes back as soon as you unplug, stop the server or quit Quail.

A closed laptop running a model gets warm. Keep it out of a bag.

Always on

To have the server there whenever the Mac is, turn on General → Open Quail at login and Server → Start the server when Quail opens, or run quail service enable.
